# Nizhal

Community website — static clone of the Webflow site, restructured with a clean frontend/backend layout.

## Live site
Hosted on GitHub Pages → `docs/` folder

## Run locally
```bash
cd frontend
npm install
node server.js
# open http://localhost:3000
```

## Structure
```
docs/          ← GitHub Pages static site (HTML + CSS + JS)
frontend/      ← source files + local dev server
backend/       ← Express API (contact form, email)
```
